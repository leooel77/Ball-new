# 🏀 籃球輪轉 — 部署說明

## 這是什麼？
一個完整的籃球場輪轉分隊管理系統，打包成 PWA 網頁應用，
任何 Android / iOS 手機平板用瀏覽器打開就能用。

## 包含檔案
- `index.html` — 完整的應用程式（所有程式碼都在這一個檔案裡）
- `manifest.json` — PWA 設定檔（讓它可以加到主畫面）

---

## 🚀 部署方式（選一個）

### 方式一：GitHub Pages（免費、最簡單）
1. 建立一個 GitHub 帳號（如果沒有的話）
2. 建立一個新的 Repository（例如叫 `basketball`）
3. 把 `index.html` 和 `manifest.json` 上傳到這個 repo
4. 到 Settings → Pages → Source 選 `main` branch → 存檔
5. 等幾分鐘後，你的 App 就會在：
   `https://你的帳號.github.io/basketball/`
6. 用手機打開這個網址就能用了！

### 方式二：Netlify（免費、拖拉上傳）
1. 到 https://app.netlify.com/drop
2. 把整個資料夾拖進去
3. 幾秒鐘後就會產生一個網址
4. 手機打開就能用

### 方式三：本機使用（不需網路）
1. 把 `index.html` 和 `manifest.json` 放到手機裡
2. 用瀏覽器打開 `index.html`
   （注意：語音功能需要網路才能載入語音引擎）

---

## 📱 加到 Android 主畫面
1. 用 Chrome 打開網址
2. 點右上角 ⋮ 選單
3. 選「加到主畫面」或「安裝應用程式」
4. 之後就跟原生 App 一樣，從主畫面直接開！

## 📱 加到 iPhone 主畫面
1. 用 Safari 打開網址
2. 點底部的分享按鈕 ⬆️
3. 選「加入主畫面」
4. 完成！

## 功能清單
- ✅ 球員資料庫（自動儲存在手機裡）
- ✅ 點選快速簽到
- ✅ 隨機分隊（黑隊 vs 白隊）
- ✅ 攻防標示（白隊先攻，贏的留場變防守）
- ✅ 連贏2場自動輪換
- ✅ 等候區優先排序（正式 > 臨打 > 已打過的）
- ✅ 場邊任務（前3人：裁判×2 + 記錄台×1）
- ✅ 臨打球員 / 優先球員（可選順位 1~10）
- ✅ 語音播報（🔊 按鈕唸出攻防名單）
- ✅ 復原上一場
- ✅ 管理球員（隨時移除離場的人）

## V2 管理功能（開發版）

- ✅ 簽到球員中途離場
- ✅ 黑白隊隊長三級順位（每級 4 人）
- ✅ 固定 5 人裁判團名單
- ✅ 可新增多個任務的定時輪值表
- ✅ 週一／週四出席點數與假日排除清單
- ✅ 四隊對抗賽、比分與個人得分／籃板／助攻／失誤
- ✅ 公告欄與 YouTube 連結
- ✅ 場上／等候球員一鍵退出
- ✅ 對抗賽數據 `+1`／`-1` 修正
- ✅ 判例交流與圖片暫存
- ✅ 完整 JSON 備份／匯入，版本更新保留既有資料
- ✅ 球員累積點數；對抗賽當天未簽到記 4 點
- ⏳ Supabase 雲端同步、管理者登入、球員唯讀查詢
- ⏳ 政府行政機關辦公日曆自動匯入
- ⏳ LINE Login／Messaging API 公告推播

目前 V2 新資料仍使用瀏覽器 `localStorage`。若要讓其他球員從各自手機查詢，必須先建立雲端資料庫並設定讀寫權限；不可把具有管理權限的金鑰直接放在公開 GitHub Pages。
